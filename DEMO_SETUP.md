# Подготовка демо SmartInspect

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000
# или production-режим, как на сервере:
npm run build && npm start
```

Для карты нужен `NEXT_PUBLIC_MAPTILER_KEY` в `.env` (значение подставляется при сборке). Остальные переменные для демо не нужны.

## Вход

`/login` → демо-доступ `demo@sminspect.ru` / `demo1234`.

## Демо-данные

- Источник — `lib/demo/seed.ts`; срез данных — 1 ноября 2026.
- Состояние кабинета хранится в `localStorage` браузера (ключ `smartinspect.demo`).
- **Сброс:** «Настройки» → блок «Демо-данные» → «Сбросить демо-данные». Удаляет созданные инспекции, изменения статусов и отчёты и возвращает исходный набор.
- Полная очистка браузера (включая вход и профиль): DevTools → Application → Local Storage → удалить ключи `smartinspect.*`.

### Видеоматериалы

Кадры `a121-video-*.jpg` извлечены из записи облёта дроном (`SmartInspect Demo Video.mp4`, 38 с) и обрезаны до 4:3; их разметка повторяет ролик `SmartInspect Demo Review.mp4`. Сами видеофайлы в приложение не встроены (они лежат в корне репозитория и не коммитятся) — их удобно показывать в видеоролике рядом с кадрами в кабинете (`SmartInspect_side_by_side.mp4`).

Загрузить снимок можно двумя способами: кнопками демо-набора в форме «Новая инспекция» или как файл с диска (скачайте его по адресу `/demo-samples/<файл>`). Пересохранённый или сжатый файл распознан не будет — это ожидаемо.

## Чек-лист перед записью

1. Браузер Chrome, окно **1920×1080**, масштаб 100%, без расширений в панели.
2. Открыть `/login`, войти в демо-доступ.
3. Принять или отклонить cookie-баннер (он перекрывает низ экрана).
4. «Настройки» → «Сбросить демо-данные» и проверить значения из таблицы выше.
5. Проверить интернет: карта грузится с MapTiler.
6. Один раз сформировать любой PDF и удалить его из «Загрузок» — чтобы прогреть сервер и проверить скачивание.
7. Закрыть уведомления ОС, включить «Не беспокоить».
8. Держать открытыми вкладки: кабинет и пустую вкладку для PDF.

## Восстановление, если что-то пошло не так

- Неверные данные или лишние инспекции → «Настройки» → «Сбросить демо-данные».
- Инспекция в статусе «Ошибка обработки» после перезагрузки страницы — ожидаемо (файлы живут только в памяти вкладки); создайте инспекцию заново.
- Не скачивается PDF → проверьте, что сервер запущен (`/api/reports/pdf` отвечает), повторите; ошибка показывается над таблицей отчётов.
- Карта серая с сообщением → нет доступа к MapTiler; список объектов справа продолжает работать.
